# Rani Tour's

Production website foundation for Rani Tour's, built from the approved UI mockups.

## Stack

- Next.js 16.3.2 (App Router)
- React 19.2.8
- TypeScript 7.0.2 (strict)
- Tailwind CSS 4.3.3
- Motion 13.1.1 (`motion/react`, the current Framer Motion package)

## Getting started

```bash
npm install
npm run dev
```

Quality check:

```bash
npm run check
```

## Current milestone

Initial visual foundation: theme tokens, responsive global header/mobile nav, hero, trip search, popular routes, destinations, CTA and footer.

## Image policy

Use properly licensed/copyright-free travel and fleet imagery. The initial hero uses a free Unsplash image of Mehrangarh Fort. Image sources/credits will be tracked as the asset library grows.
